**Switlynka (Світлинка)** — це надшвидкий, багатофункціональний і легкий переглядач графічних файлів, векторних макетів, документів PDF та відеоматеріалів із відкритим кодом. Програма поєднує можливості сучасного переглядача фото, рушія для перегляду надвеликих карт (гігапіксельних растрових масивів), інструментів інтерактивного кадрування у стилі Krita, відеопрогравача з покадровим захопленням через **FFmpeg**, розширеного конвертування за допомогою **ImageMagick**, векторного динамічного рендерингу через **Ghostscript** та **Poppler**, а також системних утиліт для діагностики й оптимізації ОС.

## 🚀 Що нового в останній версії

- 📄 **Повноцінна інтеграція діалогу OpenPDFDialog та підтримка PDF**:
  - Інтерактивне діалогове вікно вибору сторінки з візуальним прев'ю на темному тлі у стилі реалістичного паперового аркуша з м'якою тінню (Drop Shadow).
  - Миттєве визначення загальної кількості сторінок (Poppler `pdfinfo.exe`, нативний C++ in-process парсер у пам'яті за 0 мс, Ghostscript, ImageMagick) зі встановленням діапазону `1 .. totalPages`.
  - Вільний вибір роздільної здатності растеризації у полі `spinResolutionCtrl` (від 36 до 2400 DPI, за замовчуванням 300 DPI) для формування повнорозмірного майстер-растру (наприклад, 2480×3508 px при 300 DPI або 4960×7016 px при 600 DPI).
  - Внутрішньопам'ятне кешування прев'ю (`std::map<int, wxImage>`) для перегортання без затримок (0.01 мс).
  - Повна подвійна буферизація (`SetDoubleBuffered`, `wxAutoBufferedPaintDC`) із блокуванням `WM_ERASEBKGND`, що усуває мерехтіння вікна при зміні сторінок.
- ⚡ **Швидка навігація сторінками PDF у переглядачі (`Ctrl + Left` / `Ctrl + Right`)**:
  - Перехід між сторінками відкритого документа безпосередньо з клавіатури за допомогою `Ctrl + Left` (або `Page Up`) та `Ctrl + Right` (або `Page Down`).
  - Миттєве перерендерення сторінки у раніше обраному DPI без відкриття діалогу з оновленням рядка стану (`PDF: сторінка X з Y (DPI: 300)`) та таблиці властивостей.
  - Збереження штатної навігації по теці клавішами `Left` / `Right` без Ctrl.
- 💾 **Збереження реального розміру (DPI) та оновлення каталогу при перезаписі («Overwrite File»)**:
  - Пряме збереження високороздільного растру `m_originalImage` при командах «Save File As...» та «Overwrite File» без зворотного стискання у номінальні 72 DPI.
  - При виборі пункту меню «Overwrite File» для PDF автоматично експортується повнорозмірний файл `.png` у тій самій теці, оновлюються шлях і метадані, та викликається сканування каталогу (`ScanFolder`), завдяки чому новий PNG негайно з'являється у списку `m_listCtrlThisFolder`.
- 🖼️ **Потокобезпечна побудова мініатюр PDF без помилок та чорних квадратів**:
  - Розробка системної функції `RunHiddenProcessSync` на базі нативного Win32 `CreateProcessW` (`CREATE_NO_WINDOW`) із очікуванням `WaitForSingleObject` — повна ізоляція від GUI-потоку wxWidgets та ліквідація помилок `wxThread::IsMain()`.
  - Автоматична генерація чіткої мініатюри першої сторінки для всіх PDF-файлів у теці (`pdftoppm -png -r 72 -f 1 -l 1`).
  - Захист від помилок «No image handler for type» та резервна графічна плитка замість порожніх чорних квадратів.
- 🧲 **Усунення «замерзання» іконки файлу при Drag-and-Drop**:
  - Асинхронне відкладене виконання через `CallAfter` у методі `ImageDropTarget::OnDropFiles`. Системне OLE-рукостискання Windows завершується за 0.001 мс, Провідник Windows миттєво знищує графічний фантом іконки, після чого діалог відкривається абсолютно чисто.
- 📐 **Динамічний векторний рушій для SVG, EPS, AI та PDF (Vector Re-Rasterization Engine)**:
  - При наближенні зображення коліщатком миші з Ctrl (до 3200%) програма динамічно перераховує необхідний DPI та рендерить вектор з кришталевою чіткістю без розмиття ліній і шрифтів.
  - Багаторівневий конвеєр рендерингу (Tiered Mip Caching): Poppler `pdftoppm`, Ghostscript `gswin64c`, ImageMagick `magick` та нативне зчитування TIFF-прев'ю DOS EPS.
  - Фіксація растра (`ResetVectorState`) при кадруванні (`Crop Image Area`, `F6`, `F7`).
- ✋ **Інструмент «Рука» (Hand Tool, Spacebar Pan)**:
  - Панорамування полотна затисканням клавіші **Пробіл (Spacebar)** та лівої кнопки миші у режимах 100% та Custom size без ривків і шлейфів.
- 🎯 **Курсорне масштабування за зразком GIMP (Zoom Focus: Mouse Pointer)**:
  - Точка під курсором миші залишається нерухомою на екрані при наближенні та віддаленні (`Ctrl + коліщатко миші`). Діапазон від 5% (0.05x) до 3200% (32x).
- 🗺️ **Підтримка гігапіксельних зображень та карт (Display-Space Tile Grid)**:
  - Перегляд растрових мап понад 16000×16000 px у режимі 100% (1:1) за допомогою фіксованої дисплейної сітки блоків 512×512 px без вичерпання дескрипторів Windows GDI (споживання лише 12–16 МБ VRAM).
- ✂️ **Дзеркальне симетричне кадрування (Krita Style Ctrl-Crop)**:
  - Дзеркальна симетрія від центру рамки кадрування при затиснутій клавіші `Ctrl` (та комбінація `Shift + Ctrl` для симетричного пропорційного квадрата).
- 🎬 **Відеоплеєр-селектор кадрів та FFmpeg-інтеграція**:
  - Drag-and-Drop відео (MP4, MKV, MOV, AVI, WMV, MXF, TS, WebM), точний покадровий перехід за реальним FPS відео, калібрування діапазону Rec.709 TV Range (16-235) $\to$ Full PC sRGB (0-255), збереження прозорості (альфа-каналу).

## 🌟 Підтримувані формати файлів

| Категорія | Розширення файлів | Технологія обробки |
| :--- | :--- | :--- |
| **Документи PDF** | `.pdf` | Poppler `pdftoppm` / `pdfinfo`, Ghostscript `gswin64c`, нативний C++ парсер, OpenPDFDialog |
| **Векторна графіка** | `.svg`, `.svgz`, `.eps`, `.ai`, `.epi`, `.epsf` | Динамічний векторний рендеринг: Ghostscript, Poppler, ImageMagick, TIFF-екстрактор |
| **Стандартні растрові** | `.png`, `.jpg`, `.jpeg`, `.bmp`, `.gif`, `.webp`, `.tiff`, `.tif`, `.ico`, `.tga`, `.pnm`, `.xpm` | Нативне декодування wxWidgets + ImageMagick 7 з підтримкою 8-бітного альфа-каналу |
| **Відеофайли** | `.mp4`, `.mov`, `.avi`, `.mkv`, `.wmv`, `.mxf`, `.mpg`, `.mpeg`, `.ts`, `.webm` | `wxMediaCtrl` (DirectShow) + зондування та витяг кадрів через `ffmpeg.exe` |
| **Анімації** | `.gif`, `.webp`, `.png` (APNG) | Багатокадрове кешування `m_cachedAnimBitmaps` з точним таймінгом до 60 FPS |
| **Професійні та RAW** | `.heic`, `.heif`, `.avif`, `.jxl`, `.psd`, `.psb`, `.dds`, `.dng`, `.cr2`, `.nef`, `.arw`, `.exr`, `.hdr`, `.xcf` | Інтеграція з ImageMagick 7 (`-background none`, 32-бітний колір) |
| **Текстові Base64** | `.txt`, `.b64` (з префіксом `data:image/...;base64,`) | Нативне декодування `wxBase64Decode` прямо в оперативну пам'ять |

## 🔍 Режими перегляду та масштабування

Селектор режимів розміру розташовано у правому кутку рядка стану (**StatusBar**):
1. **Resizing (Fit to Window)** — повна адаптація розміру кадру під геометрію вікна з білінійним субпіксельним антиаліасингом.
2. **100% (Original100)** — відображення у справжній вихідній роздільній здатності 1:1 із центруванням та активними скролбарами. Для PDF-файлів використовує дійсний розмір, обраний у `Resolution (DPI)` (наприклад, 2480×3508 px при 300 DPI).
3. **Custom size** — довільне плавне масштабування від 5% (0.05x) до 3200% (32x) коліщатком миші з `Ctrl` або гарячими клавішами з фіксацією точки під курсором.

## 🛠️ Зовнішні залежності та переносимість (Portable)

Для максимальної швидкодії та автономної роботи програми «Світлинка» рекомендується розмістити у теці програми (поруч із `Switlynka.exe`) або прописати у системний `PATH`:

1. **Poppler для Windows (`pdftoppm.exe`, `pdfinfo.exe`)**:
   - Забезпечує миттєвий рендеринг PDF-документів та векторних макетів Adobe Illustrator (`.ai`).
   - Повний перелік необхідних бібліотек DLL описано у файлі `pdftoppm_dll_dependencies.md`.
2. **Ghostscript (`gswin64c.exe`)**:
   - Потрібен для прямого надшвидкого рендерингу PostScript / Encapsulated PostScript (`.eps`) із підтримкою субпіксельного антиаліасингу.
3. **ImageMagick 7 (`magick.exe`)**:
   - Універсальний рушій для розширених графічних форматів (SVG, HEIC, AVIF, RAW, PSD, DDS, XCF) та пакетного конвертування.
4. **FFmpeg (`ffmpeg.exe`)**:
   - Забезпечує покадрове видобування кадру з відео, точний пошук за таймкодом та пакетну конвертацію відео у послідовність зображень.

## 💻 Збірка проекту

Проект розроблений для середовища **Code::Blocks** з використанням компілятора **MinGW-w64 (GCC 8.1+ / C++17)** та бібліотеки **wxWidgets 3.2+**.

1. Відкрийте файл проекту `Switlynka.cbp` у Code::Blocks.
2. Переконайтеся, що змінні середовища або глобальні шляхи вказують на зібрану бібліотеку wxWidgets 3.2+.
3. Виберіть конфігурацію **Release** або **Debug** та виконайте збірку (**Build / Ctrl+F9**).
4. Усі вихідні файли використовують стандартне кодування Windows-1251 (CP1251) із закінченнями рядків CRLF.
