Головні нововведення останньої версії

✋
Інструмент «Рука» (Hand Tool)
Плавна навігація полотном при збільшеному масштабі:
  • Активація утриманням клавіші Spacebar у режимах 100% та Custom size.
  • Курсор трансформується у долоню, переміщення відбувається затисканням ЛКМ.
  • Апаратна синхронізація без ривків, затримок та шлейфів.
🎯
Зум під курсором (GIMP Style)
Інтуїтивне масштабування полотна:
  • Масштабування через Ctrl + Wheel.
  • Точка під курсором миші залишається нерухомою на екрані.
  • Зображення збільшується безпосередньо з-під курсора без з'їжджання вбік.
  • Безперервний діапазон наближення від 5% (0.05x) до 3200% (32x).
🗺️
Надвеликі карти місцевості
Підтримка гігапіксельних растрових масивів:
  • Перегляд растрових мап понад 16000×16000 px у режимі 100% (1:1).
  • Плитковий дисплейний рендеринг (Display-Space Tile Grid 512×512 px).
  • Повне усунення обмеження пам'яті GDI DIB section та ліквідація розтікання.
  • Сумарне споживання лише 12–16 МБ VRAM на екрані Full HD.
✂️
Симетричне кадрування (Ctrl)
Професійне трансформування рамки кадрування:
  • Подвійний клік ЛКМ або Alt + A.
  • Утримання Ctrl забезпечує дзеркальну симетрію від центру.
  • Комбінація Shift + Ctrl для симетричного пропорційного квадрата.
  • Швидке векторне малювання маркера без копіювання пам'яті (60 FPS).
🎬
Відеоплеєр і селектор кадрів
Повноцінна інтеграція з FFmpeg:
  • Drag-and-Drop відео (MP4, MKV, MOV, AVI, WMV, MXF, TS, WebM).
  • Зондування таймкоду ГГ:ХХ:СС та лічильник кадрів.
  • Покадровий крок за реальним FPS відео без збоїв DirectShow.
  • Апаратне калібрування Rec.709 16-235 у Full sRGB 0-255 та альфа-канал.
💾
Розумне збереження файлів
Зручність при щоденній роботі:
  • Автоматична підстановка імені відкритого файлу при Save As.
  • Збереження у вихідну теку та формат без зайвих кліків.
  • Пункт меню «File overwrite» для швидкого прямого перезапису.
  • Підтримка 15 кроків історії змін (Ctrl + Z).
🔍

Режими масштабування та перегляду

Три режими роботи робочого полотна (StatusBar / comboSizeImg)

У правому нижньому кутку статус-бару розташовано селектор режимів розміру зображення:

  • Resizing (Fit to Window) — повна адаптація розміру кадру під поточні розміри вікна програми.
  • 100% (Original100) — відображення в реальному вихідному масштабі 1:1 із центруванням та скролбарами. Ідеально для перевірки різкості, деталей фото та супутникових карт.
  • Custom size — плавне збільшення та зменшення полотна від 5% до 3200%. Активується автоматично при обертанні коліщатка миші з клавішею Ctrl.

Інструменти кадрування та масок

📐
Crop Image Area (Krita Style)
Активація через подвійний клік ЛКМ або пункт меню Edit → Crop Image Area:
  • 8 маркерів масштабування зі зміною курсора.
  • Перетягування центральної області для зсуву рамки.
  • Shift — пропорційне кадрування.
  • Ctrl — дзеркальне кадрування від центру.
  • Enter — виконати обрізання.
  • Esc — скасувати кадрування.
⭕
Геометричні маски F6 / F7
Швидкі інструменти малювання виділень:
  • F6 — Rectangle Mask (прямокутне або квадратне виділення).
  • F7 — Circle Mask (еліптичне або кругле виділення з прозорим фоном).
  • Субпіксельний антиаліасинг країв кола.
  • Скасування режиму через клавішу Esc.

Вбудовані системні утиліти

💻
System Information (Alt+Shift+S)
Збір системних відомостей без додаткових програм:
  • Маркетингова версія та точний UBR збірки Windows.
  • Тактова частота процесора, кількість ядер, температура ACPI.
  • Слоти RAM та обсяг виділеної відеопам'яті DXGI VRAM GPU.
  • Список фізичних дисків та вільний простір.
🚀
Autorun Manager (Alt+Shift+A)
Повний контроль автозавантаження операційної системи:
  • Гілки реєстру HKCU, HKLM, Wow6432Node та папки Startup.
  • Увімкнення, вимкнення, видалення записів автозапуску.
  • Прямий перехід до теки програми та UAC-підвищення прав.
💡
Апаратна яскравість (Alt+Shift+L)
Керування підсвіткою дисплея:
  • Пряме апаратне регулювання через шину DDC/CI монітора.
  • WMI-сумісність для ноутбуків та моноблоків.
  • Зручний повзунок без необхідності тягнутися до кнопок монітора.
