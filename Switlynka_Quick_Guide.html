Головні нововведення останньої версії

📄
Повна підтримка PDF та OpenPDFDialog
Інтеграція селектора сторінок та рендерингу високої чіткості:
  • Інтерактивне вікно OpenPDFDialog із прев'ю у вигляді білого паперового аркуша з м'якою тінню (Drop Shadow).
  • Миттєве визначення сторінок (Poppler `pdfinfo`, нативний C++ парсер у пам'яті за 0 мс) із діапазоном 1 .. totalPages.
  • Вибір роздільної здатності растеризації spinResolutionCtrl (від 36 до 2400 DPI, за замовчуванням 300 DPI) для формування повнорозмірного майстер-растру (2480×3508 px при 300 DPI).
  • Подвійна буферизація та відсутність мерехтіння при гортанні сторінок.
⚡
Гортання PDF у вікні (Ctrl + Стрілки)
Пряма клавіатурна навігація сторінками:
  • Ctrl + Left / Page Up — попередня сторінка відкритого документа.
  • Ctrl + Right / Page Down — наступна сторінка відкритого документа.
  • Миттєве перерендерення в обраному DPI без повторного відкриття діалогу.
  • Синхронне оновлення таблиці властивостей і рядка стану (PDF: сторінка X з Y (DPI: 300)).
💾
Розумний перезапис та збереження DPI
Збереження 100% чіткості растру:
  • Пряме збереження майстер-растру при «Save File As...» без зворотного стискання у номінальні 72 DPI.
  • Команда «File overwrite» для PDF автоматично експортує повнорозмірний PNG у тій самій теці.
  • Автоматичне сканування каталогу (ScanFolder) — новий PNG миттєво з'являється у списку теки.
🖼️
Безпечні мініатюри PDF у списку теки
Потокобезпечна побудова прев'ю без помилок:
  • Системна функція RunHiddenProcessSync на базі Win32 CreateProcessW без виклику черги wxWidgets.
  • Повна ліквідація фатальних помилок wxThread::IsMain() у фоновому потоці.
  • Автоматична побудова мініатюри 1-ї сторінки для кожного PDF у теці через Poppler `pdftoppm`.
  • Захисна графічна плитка — повна відсутність чорних квадратів.
🧲
Drag-and-Drop без «замерзання» іконки
Асинхронне завершення OLE Drop через CallAfter:
  • Метод OnDropFiles миттєво повертає true у підсистему OLE Windows за 0.001 мс.
  • Провідник Windows негайно знімає та знищує напівпрозору системну іконку перетягування.
  • Діалог вибору сторінки чи відео відкривається абсолютно чисто без залишкових слідів.
📐
Динамічний векторний рушій (EPS, AI, SVG)
Векторна чіткість без пікселізації:
  • Повноцінна підтримка Encapsulated PostScript (.eps) та Adobe Illustrator (.ai).
  • Динамічний перерахунок DPI при наближенні (Ctrl + Wheel) аж до 3200% через Tiered Mip Caching.
  • Миттєве зчитування вбудованого TIFF-прев'ю DOS EPS за < 1 мс.
  • Конвеєр: Ghostscript gswin64c, Poppler pdftoppm, ImageMagick 7.
✋
Інструмент «Рука» (Hand Tool)
Плавне панорамування при великому зумі:
  • Активація утриманням клавіші Spacebar у режимах 100% та Custom size.
  • Курсор трансформується у долоню, переміщення відбувається затисканням ЛКМ.
  • Апаратна синхронізація без ривків, затримок та шлейфів.
🎯
Зум під курсором (GIMP Style)
Інтуїтивне масштабування полотна:
  • Масштабування через Ctrl + Wheel.
  • Точка під курсором миші залишається нерухомою на екрані при наближенні та віддаленні.
  • Діапазон наближення від 5% (0.05x) до 3200% (32x).
🗺️
Надвеликі карти місцевості
Підтримка гігапіксельних растрових масивів:
  • Перегляд карт понад 16000×16000 px у режимі 100% (1:1).
  • Дисплейний плитковий рендеринг (Display-Space Tile Grid 512×512 px).
  • Повне усунення ліміту пам'яті GDI DIB section (лише 12–16 МБ VRAM).
✂️
Симетричне кадрування (Ctrl-Crop)
Професійне трансформування рамки у стилі Krita:
  • Подвійний клік ЛКМ або Alt + A.
  • Утримання Ctrl забезпечує дзеркальну симетрію від центру.
  • Комбінація Shift + Ctrl для симетричного пропорційного квадрата.
🎬
Відеоплеєр і селектор кадрів
Повноцінна інтеграція з FFmpeg:
  • Drag-and-Drop відео (MP4, MKV, MOV, AVI, WMV, MXF, TS, WebM).
  • Зондування таймкоду та лічильник кадрів. Покадровий крок за реальним FPS відео.
  • Калібрування Rec.709 16-235 у Full sRGB 0-255 та збереження альфа-каналу.
🔍
Повна підтримка прозорості (Alpha)
Чистий альфа-канал без білого тла:
  • Параметр -background none png32: у ImageMagick для векторних SVG, HEIC/HEIF, AVIF, WebP.
  • Підтримка шарів Photoshop PSD/PSB, DDS, TIFF та XCF.
  • Автоматична конвертація 1-бітних масок (GIF, ICO) у плавний 8-бітний альфа-канал.

Робота з багатосторінковими документами PDF

Діалогове вікно OpenPDFDialog та робочий процес

Програма «Світлинка» надає професійний інструментарій для відкриття, попереднього перегляду та растеризації окремих сторінок PDF-файлів будь-якої складності:

  • Точки входу: відкриття через меню File → Open File... (Ctrl+O), перетягування файлу мишею у вікно програми (Drag-and-Drop), запуск через командний рядок або подвійний клік на файл у панелі теки.
  • Миттєве сканування сторінок: перед відкриттям вікна утиліта pdfinfo або нативний C++ аналізатор миттєво зчитують кількість сторінок та виставляють діапазон лічильника Page Number: 1 .. N.
  • Живий попередній перегляд: при зміні сторінки стрілками спінера або введенні номера з клавіатури у панелі Preview за 15–25 мс рендериться мініатюра сторінки (72 DPI). Раніше переглянуті сторінки кешуються в пам'яті і відображаються миттєво (0.01 мс).
  • Вибір роздільної здатності (DPI): у полі Resolution користувач може вказати будь-яку щільність пікселів:
    • 72 DPI — чорновий екранний перегляд (A4 ≈ 595×842 px).
    • 150 DPI — читання електронних документів (A4 ≈ 1240×1754 px).
    • 300 DPI (Стандарт) — поліграфічна якість для детального аналізу та друку (A4 ≈ 2480×3508 px).
    • 600 DPI / 1200 DPI — надвисока чіткість для векторних креслень і карт (A4 ≈ 4960×7016 px).
  • Клавіатурне гортання у переглядачі: після завантаження сторінки комбінації Ctrl + Left та Ctrl + Right (або Page Up / Down) дозволяють перегортати сторінки безпосередньо на робочому полотні із збереженням обраної роздільної здатності.

Динамічний векторний рушій (SVG, EPS, AI, PDF)

Математика векторного масштабування (Tiered Mip Caching)

На відміну від звичайних переглядачів, які один раз розтягують растрову картинку, «Світлинка» аналізує векторні структури в реальному часі:

  • Динамічний перерахунок DPI: формула $\text{DPI} = \text{clamp}(72.0 \times \text{scale}, 72, 1200)$ автоматично підвищує щільність рендерингу при збільшенні масштабу користувачем.
  • Квантизація та пам'ять 60 FPS: квантування на рівні 72, 108, 144, 216, 288, 432, 576, 864 DPI утримує готовий растр у пам'яті m_vectorRenderCache, завдяки чому панорамування Hand Tool та мікрозум працюють зі швидкістю понад 60 кадрів/сек без повторного виклику дисків.
  • Ізоляція кадрування: при виконанні обрізки (Crop Area, маски F6/F7) викликається ResetVectorState(), що фіксує кадровий фрагмент як незалежний растр без скидання на загальний векторний файл.

Режими масштабування та перегляду

Три режими роботи полотна (StatusBar / comboSizeImg)

У правому нижньому кутку статус-бару розташовано селектор режимів розміру зображення:

  • Resizing (Fit to Window) — повна адаптація розміру кадру під поточні розміри вікна програми з плавним білінійним субпіксельним антиаліасингом.
  • 100% (Original100) — відображення в реальному вихідному масштабі 1:1 із центруванням та скролбарами. Для PDF-сторінок відображає дійсний піксельний розмір обраного DPI (наприклад 2480×3508 px при 300 DPI).
  • Custom size — плавне збільшення та зменшення полотна від 5% до 3200%. Активується автоматично при обертанні коліщатка миші з клавішею Ctrl.

Інструменти кадрування та масок

📐
Crop Image Area (Krita Style)
Активація через подвійний клік ЛКМ або пункт меню Edit → Crop Image Area (Alt+A):
  • 8 маркерів масштабування зі зміною курсора миші.
  • Перетягування центральної області для вільного зсуву рамки.
  • Shift — пропорційне збереження сторін (квадрат / співвідношення).
  • Ctrl — дзеркальне симетричне кадрування сторін від центру.
  • Enter — виконати обрізання / Esc — скасувати режим.
⭕
Геометричні маски F6 / F7
Швидкі інструменти малювання виділень:
  • F6 — Rectangle Mask (прямокутне або квадратне виділення).
  • F7 — Circle Mask (еліптичне або кругле виділення з прозорим фоном).
  • Субпіксельний антиаліасинг країв кола на основі нормалізованої відстані.
  • Скасування режиму через клавішу Esc.

Вбудовані системні утиліти

💻
System Information (Alt+Shift+S)
Збір системних відомостей без стороннього ПЗ:
  • Маркетингова версія та точний UBR збірки Windows з реєстру.
  • Тактова частота процесора, кількість ядер, температура ACPI.
  • Слоти RAM та обсяг виділеної відеопам'яті DXGI VRAM GPU.
  • Список фізичних дисків та вільний дисковий простір.
🚀
Autorun Manager (Alt+Shift+A)
Повний контроль автозавантаження ОС:
  • Гілки реєстру HKCU, HKLM, Wow6432Node та папки Startup.
  • Увімкнення, вимкнення, видалення записів автозапуску.
  • Прямий перехід до теки програми та UAC-підвищення прав.
💡
Апаратна яскравість (Alt+Shift+L)
Керування підсвіткою монітора:
  • Пряме апаратне регулювання через шину DDC/CI монітора.
  • WMI-сумісність для ноутбуків та моноблоків.
  • Зручний повзунок без необхідності тягнутися до кнопок монітора.
🔧
System PATH Editor (F5)
Графічний редактор шляхів оточення:
  • Зручний список шляхів із підрахунком кількості записів.
  • Додавання, редагування, зміна порядку пріоритету (Up/Down).
  • Пряме відкриття вибраної теки у Провіднику Windows.
